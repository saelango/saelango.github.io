### Introduction to Data Set
This data set consists of thousands of zip codes, each with corresponding data regarding any health violations, lead and copper presence in water, flood risk, air quality, demographic information, and more. 
### Potential Application
This data set has signification potential applications. It can be used to assess environmental safety concerns for each zip code. With the various data collected for each area, the severity of any environmental safety concerns can be established as well. This data set, especially if used with others, can serve as an example of computational social science, where theories and conclusions can be made in respect to the state of environmental safety in certain areas, and potential causes and impacts to the residents.
